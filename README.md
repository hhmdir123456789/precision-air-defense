# 🎯 精准防空 - 视觉认知与动态视力训练器
> **Precision Air Defense - Vision Trainer**

## ✨ 核心特色 (Features)
*   **极致视觉**：满屏霓虹光网、粒子拖尾、动态残影，兼顾视觉冲击力与流畅度。
*   **硬核训练**：告别无聊的点击，真正从认知科学角度设计玩法。
*   **量化评估**：单局结束生成认知报告，包含毫秒级平均反应时间、视觉预判准确率。
*   **双人同屏**：支持双人合作模式，考验默契与分工。
*   **纯本地运行**：无后端，无需网络，数据保存在浏览器本地，保护隐私。

## 🧠 四大训练模式 (Training Modes)
1.  **基础追踪 (Basic Tracking)**：起步20个光球，每关+10个（上限300）。锻炼多目标动态追踪能力。
2.  **抗干扰训练 (Anti-Interference)**：只打红色目标，打中蓝色干扰球扣时间。锻炼大脑的视觉搜索与抑制控制能力。
3.  **视觉暂留 (Visual Persistence)**：光球周期性隐身（0.6秒显/0.6秒隐），强制锻炼轨迹预判能力。
4.  **双人协作 (Dual Player)**：双人同屏合作，共享过关进度，适合情侣或朋友一起挑战。

## 🎮 操作指南 (How to Play)
*   **PC 端**：
    *   单人：鼠标移动瞄准，点击左键发射单发。
    *   双人：P1 鼠标移动 + 左键射击；P2 键盘 `A` / `D` 旋转炮管，`空格键` 发射。
*   **移动端**：
    *   单人：手指触摸屏幕任意位置，炮塔自动瞄准并自动发射。
    *   双人：P1 触摸屏幕左半部分；P2 使用屏幕右下角虚拟按键（←、→、发射）。

## 🛠️ 技术栈 (Tech Stack)
*   **核心引擎**：原生 HTML5 Canvas API（无第三方库依赖，极致轻量）。
*   **音频系统**：Web Audio API（代码程序化生成音效，随关卡变换）。
*   **数据存储**：LocalStorage（本地排行榜与成绩记录）。
*   **性能优化**：动态分辨率适配、Delta Time 物理补偿、高频遍历裁剪、自适应性能降级。
